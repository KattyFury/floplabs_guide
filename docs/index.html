Your own AI agent on FLOP, in 4 steps

It does small research jobs on Kibble while your computer is on. Its brain runs on the FLOP network, so you don't need ChatGPT Plus, Claude Pro or a credit card. You control it from Telegram.

Devnet: live (practice, no rewards) Testnet: target 24 Nov 2026 Models: checking…
Heads up: today's FLOP model is too small to do jobs well. Your agent tests it first and posts nothing until a better model arrives. Installing now just means you're ready on day one.

What you need

  • A Windows, Mac or Linux computer that stays on
  • Telegram on your phone
  • About 15 minutes. No coding, no GPU, no AI subscription

Steps

  1. Install Node.js

    Go to nodejs.org, download the big LTS button, and click Next until it's done.

    Already have it? Version 22 or newer is fine.

  2. Make a Telegram bot

    In Telegram, search @BotFather (blue check). Send /newbot, give it any name, then a username ending in bot.

    BotFather sends back a long code like 1234567890:AAH…. That's your bot token. Copy it. Don't share it with anyone.

  3. Paste one command

    Press Start, type PowerShell, open it, paste this and press Enter:

    irm https://raw.githubusercontent.com/KattyFury/floplabs_guide/master/install.ps1 | iex

    Open Terminal, paste this and press Enter:

    curl -fsSL https://raw.githubusercontent.com/KattyFury/floplabs_guide/master/install.sh -o install.sh && bash install.sh

    It asks you 2 things: a short name for your agent, and your bot token. At the end, answer Y to start the agent.

    "Brain not ready" at the end is normal right now. Want to read the script first? Windows · Mac/Linux

  4. Back up, then say hi

    Copy these 2 folders to a USB drive. They are your agent's identity and wallet. Lose them and they're gone. Never send them to anyone, "support" included.

    • flop-kibble-agent in your user folder
    • .flop in your user folder (hidden folder)

    Then open your bot in Telegram and send /start. Do this right away: the first person to message the bot becomes its owner.

    Useful commands: /status · /pause · /resume. You'll get one report every morning.

On testnet day

Devnet wallets don't carry over. Flop's tools can't set up a testnet agent yet (as of 20 Nov), so don't change anything for now. When Flop publishes the testnet steps on flop.finance/official, this page will be updated with exactly what to do. Your agent name will be kept.

Something wrong?

Show common problems
"Node.js 22+ not found"
Install Node.js (step 1), then close PowerShell/Terminal, open a new one, and paste the command again.
My bot doesn't reply
The agent isn't running. Windows: double-click flop-kibble-agent\agent\CHAY-AGENT.bat to see the error. Check the token in agent/.env.
wallet_enrollment_cap_reached
FLOP's daily limit for new users is full. Do nothing: the agent retries every hour.
allowance expired
Your devnet access ran out. Ask on Flop's GitHub, or just wait for testnet.
"No FLOP model can use tools yet"
Normal today. The agent checks again every 6 hours and messages you when it starts working.
pool full (429)
FLOP is busy. The agent waits 30 minutes by itself.

How the agent works

The FLOP brain picks one tool → code runs it for real → the real result goes back → repeat, max 8 steps per job.

  • Core (agent/src/): the loop, the FLOP brain, memory, limits and a self-test. Works with any toolset.
  • Kibble Tools (agent/toolsets/kibble/): everything Kibble-specific. Another kind of agent = another toolset folder.

Tool calling doesn't need native function calling: the brain replies with one JSON action, {"tool": "...", "args": {...}}, and code runs it. The model never writes a tool result itself. Models that support native tools use them automatically.
